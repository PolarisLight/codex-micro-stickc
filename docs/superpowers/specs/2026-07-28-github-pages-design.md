# Codex Micro StickC GitHub Pages 设计规格

## 目标

为 `codex-micro-stickc` 提供一个移动端优先的单页项目主页，重点展示本项目完成的 StickC 控制器、会话切换、命令控制和会话名称同步。页面通过 GitHub Pages 发布，只部署 `site/` 目录。

## 受众与叙事

主页首先服务于从短视频、小红书或 GitHub 进入的访客。历史来源只用一小段带过：

1. Codex Micro 提供灵感。
2. 社区 Stream Deck 项目验证了控制思路。
3. Core2 固件带来 ESP32 实现基础。
4. 本项目将其适配到 M5StickC Plus，并加入跨平台名称同步和离线回退 UI。

页面主叙事围绕四张真实渲染图展开：

- 产品封面
- 六会话切换
- Codex 命令控制
- 会话名称同步

## 视觉方向

- `DESIGN_VARIANCE: 7`
- `MOTION_INTENSITY: 3`
- `VISUAL_DENSITY: 4`
- 单一深色主题，近黑背景，橙色作为主操作色。
- 蓝色和绿色只用于表达固件状态。
- 使用系统字体，避免第三方字体请求。
- 使用真实 UI 渲染图，不以 HTML 模拟设备屏幕。
- 版式采用编辑式长页和错落图片，不使用常见三卡片模板。

## 页面结构

1. 顶部导航：项目名、GitHub、开始使用。
2. Hero：一句产品定义、核心能力、产品封面。
3. 项目来源：用短时间线说明 Codex Micro、Stream Deck、Core2 到 StickC。
4. 使用故事：三张图解释切会话、发命令、同步名称。
5. 工作方式：设备端固件与本地同步服务的关系，以及 USB 优先、macOS BLE 回退。
6. 安装入口：链接 README 和 GitHub 仓库。
7. 页脚：开源来源和非官方项目声明。

## 隐私与安全

- 页面和图片不得出现本机绝对路径、真实任务标题、蓝牙地址、串口名或设备标识符。
- GitHub Pages 工作流只上传 `site/`，不上传仓库根目录。
- 页面不包含统计、Cookie、表单或第三方脚本。

## 可访问性与响应式

- 使用语义化 HTML、跳转主内容链接和可见焦点状态。
- 所有图片提供中文替代文本。
- 图片延迟加载，首屏封面除外。
- 支持 `prefers-reduced-motion`。
- 重点验证 360px 手机宽度和常见桌面宽度。
