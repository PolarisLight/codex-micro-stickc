WHERE IT CAME FROM

从桌面旋钮，到口袋控制器。

  1. 01

    Codex Micro

    官方概念给了它一套清楚的交互语言。

  2. 02

    Stream Deck

    社区逆向项目把会话控制带到了现成硬件。

  3. 03

    Core2 firmware

    ESP32 固件提供了继续适配的起点。

  4. 04

    StickC edition

    更小的硬件、真实标题、跨平台部署和离线回退。

01 / SWITCH

一只手，切换六个会话。

屏幕直接显示当前槽位和任务名称。短按切换，长按进入， 录视频、调试硬件或同时跑多个 Agent 时都不用碰鼠标。

  • A下一个会话
  • B打开当前会话
  • 1/6左上角显示位置

02 / CONTROL

常用命令，变成实体按键。

继续、打断、确认、取消。高频动作留在手边， 设备负责输入，Codex 仍然在电脑上完成真正的工作。

03 / NAME SYNC

状态告诉你发生了什么，名称告诉你该去哪里。

本地服务监听 Codex 的会话绑定变化，把标题同步到设备。 有线连接时优先走 USB，macOS 拔线后可通过 BLE 继续更新。

→
StickC BLE 回退

全程在本机运行。页面不上传任务内容，也不依赖云端中转。

BUILD YOURS

一套项目，macOS 和 Windows 都能部署。

刷入 StickC 固件，再启动桌面同步服务。即使同步服务没有运行， 设备也会回退到干净的 Agent 编号界面。
